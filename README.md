# FixGhar APK build branch

This branch is an isolated Android build workspace for FixGhar; the repository default branch is untouched.

Source: `fixghar_source.zip`. CI workflow: `.github/workflows/fixghar-apk.yml`.

Run **Actions → FixGhar Android APK** and download the `FixGhar-Android-APK` artifact ZIP. Extract `app-debug.apk` and install it on your Android phone.

This debug APK is for personal testing and is not Play Store signed.
